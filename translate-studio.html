Duo Translate

A browser extension that translates web pages and puts the translation under each paragraph, so you can read both. Free, no account. Works in Chrome, Brave, Edge and Firefox on Windows and Mac.

Paragraphs get the translation underneath. Short labels like tabs and buttons are swapped in place so the layout doesn't break.

Install

    Using it

    Turn it on

    Press Alt A (Control Shift A on a Mac), or right-click the page and pick Translate page. Same again to show the original.

    Both or translation only

    Click the extension icon to switch between showing both languages and the translation alone, and to pick the language.

    Always translate a site

    Tick Always translate in the popup and that site opens translated every time.

    Fast on long pages

    Only what's on screen is translated. The rest follows as you scroll, and new content is picked up as it loads.

    Where the text goes

    Unlike the other tools here, this one sends text off your machine. Page text goes to Google Translate's free endpoint, the same one Chrome's own translate menu uses. In Chrome 138 and later you can download Chrome's on-device model from the popup. Then pages in that language are translated on your computer and work offline. Brave, Edge and Firefox don't include that model, so they always use Google.
