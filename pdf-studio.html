How to use
  • Add files by dropping them on the page or using + Add files. Everything happens in your browser — nothing is uploaded anywhere.
  • Click an operation on the right. Only operations that make sense for your current files are enabled (e.g. Merge needs 2+ PDFs).
  • Most page-based operations show a thumbnail grid — click pages to select them, or type a range like 1-3,5,7-9.
  • Results download automatically. Operations that produce several files bundle them into one .zip.
What's genuinely exact vs. best-effort
Exact, byte-for-byte operations (no quality loss): Merge, Split, Remove/Extract/Reorder pages, Rotate, Add page numbers, Watermark, Edit metadata, Image ↔ PDF.

Best-effort, by necessity — a browser cannot drive the real Word, PowerPoint, or Excel application the way a desktop tool can, so these use the closest honest alternative instead of faking exactness:
  • Excel → PDF reads your actual cell data and draws a real, paginated table — exact for plain data, but won't reproduce charts, cell colors, or complex formatting. Only WinAnsi (Western) characters can be drawn; other scripts may fail to render a cell.
  • Word → PDF and PowerPoint → PDF convert the real text and structure to a clean HTML preview, then hand off to your browser's own print dialog — choose “Save as PDF” there. This uses your browser's real, high-quality PDF renderer, but you take one extra manual step, and PowerPoint slide design/images aren't reproduced, only the words.
  • PDF → Word extracts the text of each page into a plain .docx — original layout, fonts, and images are not reconstructed.
